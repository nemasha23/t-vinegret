# Т-Винегрет: приём ответов

Простая платформа для онлайн-квиза. Участники отвечают с телефона, ведущая переключает вопросы кнопкой «Дальше», ответы проверяются автоматически. Вопросы показываются на презентации ведущей, сайт только собирает ответы.

- Страница участника: `https://<адрес>/`
- Страница ведущей: `https://<адрес>/admin` (по паролю)

Внешних библиотек нет, нужен только Node.js 18 или новее.

## Как запустить на Render (один раз, минут 15)

1. Зайди на [render.com](https://render.com) и войди через GitHub (кнопка «GitHub»).
2. Нажми **New → Blueprint** и выбери репозиторий `t-vinegret`. Если его нет в списке, нажми «Configure account» и дай Render доступ к этому репозиторию.
3. Render прочитает файл `render.yaml` и попросит значение **ADMIN_PASSWORD**. Придумай пароль ведущей и введи его.
4. Нажми **Apply**. Через пару минут сервис станет зелёным (Live), а вверху появится адрес вида `https://t-vinegret-xxxx.onrender.com`.
5. Открой этот адрес с телефона: должна появиться форма регистрации. Открой `адрес/admin` на компьютере и войди с паролем.

Тариф в `render.yaml` стоит **Starter** (около $7 в месяц, списывается за фактическое время работы). Бесплатный тариф засыпает после 15 минут без посетителей, просыпается около минуты и слабоват для 500 человек. После игры сервис можно удалить или перевести на Free в настройках (Settings → Instance Type).

## Перед игрой

1. **Репетиция за день.** Открой `/admin`, позови 5–10 человек с телефонами, пройди несколько вопросов, посмотри, как всё переключается. Потом нажми «Стереть всё и начать заново» (нужно напечатать СБРОС).
2. **QR-код.** Сделай QR на адрес сайта (например, на qr-code-generator.com) и поставь на первый слайд.
3. **За 15 минут до начала** открой `/admin` на компьютере и не закрывай вкладку до конца игры: она каждые 20 секунд сохраняет копию всех данных в браузере.

## Во время игры

- Участники регистрируются, на телефоне видят «Ты в игре, ждём начала».
- **«Дальше →»** переключает всех на следующий шаг. Порядок: демо-вопрос блока, вопросы, пауза на разбор, следующий блок. Под кнопкой написано, что будет дальше.
- **«← Назад»** возвращает на шаг назад (если нажала лишний раз). Ответы не теряются.
- Пока вопрос на экране, ответ можно менять, засчитывается последний. После «Дальше» приём ответов на этот вопрос закрыт.
- В таблице «Ответы на текущий вопрос» видно все варианты, которые прислали. Если автопроверка ошиблась, нажми «Засчитать» или «Не засчитывать»: решение применится ко всем, кто ответил так же.
- Рейтинг видишь только ты: общий топ-15 и топ-5 по каждому блоку.
- Галочка «Пускать опоздавших» включена. Если снять, после старта новые участники увидят: «Прости, игра уже идёт…».

## Подсчёт очков

| Блок | Очки |
|---|---|
| I. Две правды, одна ложь | 15 вопросов × 1 |
| II. Т-Перевёртыши | 15 × 1 |
| III. Т-Блиц с собесов | 7 × 2 |
| IV. Т-Пентагон | 4 темы: 3 очка с первой попытки, 2 со второй, 1 с третьей |
| V. Т-ЧГК | 9 × 2 |
| **Максимум** | **74** |

Демо-вопросы не засчитываются. При равенстве очков выше тот, у кого больше очков в ЧГК, иначе место делится.

Проверка ответа: регистр, пробелы, знаки препинания и «ё/е» не важны, латинские буквы-двойники считаются русскими. В числовых ответах берётся первое число («7,5 минут» = 7.5). В блоках II, IV и V прощается одна опечатка в словах от 6 букв. Варианты ответов лежат в `questions.js`.

## После игры

Нажми **«Скачать результаты (Excel)»**: в таблице места, имена, ники, кружки, очки по блокам и все ответы каждого участника. И на всякий случай **«Скачать резервную копию»**.

## Если что-то пошло не так

- **Сервер перезапустился, данные пропали.** На странице ведущей появится красная плашка «Похоже, сервер перезапустился». Нажми «Восстановить из копии в браузере». У участников ничего делать не нужно: телефоны сами переподключатся и перерегистрируются.
- **Сайт не открывается совсем.** В Render нажми на сервис → Manual Deploy → Restart service (или Deploy latest commit). Через 1–2 минуты открой `/admin` и восстанови данные из копии в браузере.
- **У участника «Нет связи».** Плашка внизу экрана исчезнет сама, когда связь вернётся. Если ответ не ушёл, надо нажать «Отправить» ещё раз.
- **План Б.** Держи заготовленную Google-форму с одним полем на случай, если сайт недоступен дольше 5 минут.

## Для разработчика

```bash
npm start                 # http://localhost:3000, пароль ведущей по умолчанию: vinegret
npm test                  # проверка автопроверки и прогон игры на 100 участников
node test/load.test.js 500
```

Переменные окружения: `PORT`, `ADMIN_PASSWORD`, `DATA_DIR` (куда сохранять `state.json`).
